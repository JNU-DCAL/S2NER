# BOOK 재태깅 사전

조선왕조실록·승정원일기의 서명(BOOK) 개체명 재태깅에 사용한 판정 사전이다.
표준 사전이 아니라 판정 도구이며, 두 코퍼스에서 관찰된 표현을 기반으로 구축하였다.
해당 유형의 모든 개체를 망라하지 않는다. 사전에 없는 표현은 재태깅 대상에서 제외된다.

본 사전은 서명과 그 내부 참조(편·장·조 등)의 **경계 분리**만을 다룬다.

## 파일

### book_component.csv — 서명 구성 요소 사전 (113종)

서명을 본체와 내부 참조로 분해하는 판정 목록이다.

| 열 | 설명 |
|---|---|
| 표제어 | 구성 요소 문자열 |
| 구분 | 본체 / 중간층 / 편명 / 부가어 |
| 하위분류 | 경전·역사서 / 법전 / 육전 / 書 구분 / 판본·위치 표시 |

`본체`는 분리의 시작점이 되는 경전명·법전명·역사서명이다(43종).
`중간층`은 본체와 편명 사이에 오는 단위로, 법전의 육전(`吏典`·`戶典` 등)과
『서전』의 書 구분(`周書`·`虞書` 등)이 있다(10종).
`편명`은 서적 내부의 편·장·조항명이다(56종).
`부가어`는 판본이나 위치를 표시할 뿐 저작이 아니므로 분리하되 BOOK으로
태깅하지 않는다(`前`·`後`·`幷序`·`懸吐`).

구성 요소는 두 코퍼스에서 BOOK으로 태깅된 표면형을 검토하여 선정하였다.

### book_split.csv — 분리 대상 목록 (704종)

규칙을 적용해 분해한 결과이다.

| 열 | 설명 |
|---|---|
| 표제어 | 정규화된 서명 전체 문자열 |
| 본체 | 분리 후 앞부분 |
| 분리결과 | 본체를 뗀 나머지. ` \| `로 구분 |
| 분리층수 | 분해된 조각 수 (2 또는 3) |
| 규칙 | 적용된 분리 규칙 |
| 부가어 | 조각 중 BOOK으로 태깅하지 않는 것 |
| 검수표시 | 값이 있으면 자동 분해가 불확실하여 연구자 확인을 거친 행 |

규칙별 내역은 `법전+[육전]+조항` 560종, `본체+[중간층]+편명` 106종,
`경전+편명+상하` 38종이다.

### book_keep.csv — 통째 유지 목록 (13,506종)

분리 규칙에 해당하지 않아 기존 span을 그대로 두는 서명이다.
관서명+문서종류(`備邊司謄錄`·`政院日記`)와 온전한 저작명(`大典通編`·`資治通鑑`)이
여기 속한다.

## 적용 원칙

서명은 본체로 시작할 때에만, 그 뒤가 확정된 내부 참조로 이어지는 경우에
분리한다. 본체 뒤의 잔여 문자열이 중간층·편명 목록으로 **완전히 분해될
때에만** 분리하며, 목록에 없는 표현이 남으면 통째로 유지한다. 이 조건에
의해 `孟子集註大全`과 같은 단일 저작명은 보존된다.

분리 판정 전에 표면형을 정규화한다. 교감표기 `오자[정정]`은 정정형을
채택하고(`大典道編[大典通編]` → `大典通編`), 서명부호(`《》`·`〈〉`·`『』` 등)와
양끝 문장부호를 제거한다.

## 알려진 한계

- 태깅되지 않은 위치에 BOOK을 새로 추가하는 작업은 다루지 않았다. 총서
  집합 서명(`四書`·`六經`)의 누락 보강이 이에 해당하며, 해당 표현이 경전
  집합을 지시하는지를 가르는 어휘적 단서가 규칙적이지 않기 때문이다.
- 중간층 분리는 육전 체계를 갖춘 법전에 한해 적용되었다. 『국조오례의』의
  `序例`·`續編` 등 다른 편제는 본 라운드의 목록에 포함되지 않아 2분리로
  처리되었다.
- 원문 텍스트 자체의 교감(오자 수정)은 범위에 포함하지 않는다.
