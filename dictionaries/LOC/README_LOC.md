# LOC 재태깅 사전

조선왕조실록·승정원일기의 지명(LOC) 개체명 재태깅에 사용한 판정 사전이다.
표준 사전이 아니라 판정 도구이며, 두 코퍼스에서 관찰된 표현을 기반으로 구축하였다.
해당 유형의 모든 개체를 망라하지 않는다. 사전에 없는 표현은 재태깅 대상에서 제외된다.

## 파일

### loc_building.csv — 건물명 사전 (10,033종)

건물명과 부속 요소의 결합 판정에서 좌측 검증에 사용한다.
`殿`·`門`·`宮`·`樓`·`亭`·`閣`·`堂`·`軒`·`齋`·`臺`·`館`·`寺`·`廟`·`壇`·`庫`·`倉`·`陵`·`園`·`墓`로
끝나는 LOC 표면형을 집계하였다.

### loc_attachment.csv — 부속 요소 사전 (331종)

건물명 뒤에 오는 요소의 처리 방침이다.

| 열 | 설명 |
|---|---|
| 표제어 | 부속 요소 문자열 |
| 처리 | 병합 / 유지 / 위치어 / 배제 / 관서제거 |
| 배제사유 | 배제·위치어로 판정한 근거 |
| 대표예시 | 해당 요소가 결합한 최다 빈도 표현 |

`병합`은 선행 건물명과 하나의 LOC로 묶는다(`月臺`, `望廟樓`). `위치어`는 상대
위치만 표시하므로 span에서 제외한다(`外`, `前`, `後`). `배제`는 임시 시설이나
상태 서술이어서 장소를 지시하지 않는 경우이다(`廬次`, `有頉處`). `유지`는
독립 건물명이므로 결합하지 않고 별개 span으로 둔다.

병합과 유지의 구분은 결합 비율(결합 출현 ÷ (결합 + 단독 출현))로 판정하였다.
비율 0.5 이상을 부속 요소로 본다. `月臺`는 0.95, `永寧殿`은 0.06이다.

### loc_gazetteer.csv — 행정 지명 사전 (1,961종)

위계가 중첩된 지명을 분해하는 단위이다.

| 열 | 설명 |
|---|---|
| 표제어 | 지명 |
| 단위 | 道 / 邑 / 鎭堡 등 |
| 도 | 소속 도 |
| 읍격 | 府 / 牧 / 郡 / 縣 등 |
| 진관 | 소속 진관 |
| 상위 | 상위 행정 단위 |
| 표준형 | 별칭인 경우 대응하는 표준 지명 |
| 전거 | 근거 자료 |
| 신뢰도 | 구축 근거의 등급 |
| 별칭여부 | `별칭`이면 관행적 별칭 표기 |

관행적 별칭 22종을 포함하였다(`湖西`→`忠淸道`, `松都`→`開城`, `箕城`→`平壤` 등).
별칭은 표준 지명과 동일하게 LOC로 태깅하며, `표준형` 열은 개체 연결 시
참조용으로만 제공한다.

4자 이상 결합형은 수록하지 않았다. `京畿楊州`가 단위가 되면 `京畿楊州地`가
`{京畿楊州}`로 잘못 처리되기 때문이다.

### loc_office.csv — 지명+관직 결합형 사전 (1,404종)

관직명에 포함된 지명의 경계를 확정하는 데 사용한다.
『경국대전』 등 법전에 근거해 결합형 내부의 지명과 관직 경계를 기재하였다.

| 열 | 설명 |
|---|---|
| 표제어 | 지명+관직 결합형 |
| 지명 | 표제어 앞부분의 지명 |
| 지명끝 | 지명이 끝나는 문자 위치 |
| 관직 | 표제어 뒷부분의 관직명 |
| 품계 | 관직의 품계 |
| 유형 | 外官-文 등 |
| 전거 | 근거 법전 |
| 시행 | 시행 연도 |

`慶州府尹`은 지명 `慶州`[0:2]와 관직 `府尹`[2:4]으로 분해되며, 지명만 LOC로
태깅한다. 사전에 없는 후보는 추정 태깅하지 않는다.

### loc_blocklist.csv — 차단어 사전 (417종)

지명으로 판정해서는 안 되는 표현 목록이다. 주로 지명+관직 결합형의 분해에서
오탐을 막는 데 사용한다.

| 열 | 설명 |
|---|---|
| 표제어 | 차단 대상 문자열 |
| 분류 | 지명 아님 / 관형어 / 관서명 / 중앙관직 |
| 적용조건 | 무조건 / 지명 선행 없음 |

`관형어`는 지명 앞에 붙는 수식 요소로 span에 포함하지 않는다(`本道`, `該`, `新`).
`중앙관직`은 지명이 선행하지 않는 관직이므로 앞부분을 지명으로 보지 않는다
(`領議政`, `承旨`). 사전에 없는 후보는 추정 태깅하지 않는다.

### loc_exclusion.csv — 제외·유지 판정 목록 (646종)

LOC로 태깅되어 있었으나 지명이 아닌 항목의 처리 결과이다.

| 열 | 설명 |
|---|---|
| 표제어 | 기존 LOC 태깅 문자열 |
| 처리 | 제거 / 분할 / 국호유지 / 유지 |
| 재태깅결과 | 중괄호 표기. 제거는 공란 |
| 제외어 | span에서 제외한 문자열 |
| 유형 | 종족명 / 국호 / 관서명 등 |
| 출처구분 | 종족·국호 / 관서 |

종족명은 행위 주체로 등장하므로 지명이 아니다(`兀良哈`, `野人`). 다만 국호는
지명으로 유지하며(`倭`, `漢`, `唐`), 국호나 지역명에 `人`이 결합한 형태는
앞부분만 남긴다(`倭人` → `{倭}`). 관서는 장소가 아니라 기관을 지시하므로
제외한다(`漢城府`, `長興庫`).

## 알려진 한계

- 이표기 통합(`景慕宮`/`景廟宮`), 시대별 지명 개칭(`永安道`→`咸鏡道`)은 다루지 않았다.
- 관직명 자체의 태깅은 범위 밖이며, 지명만 LOC로 태깅한다.
